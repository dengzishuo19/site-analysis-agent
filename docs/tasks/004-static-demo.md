# 派工单 004：静态演示页（单个 HTML 文件）

状态：已完成并验收

## 背景
在线版尚未部署，且国内访问 Vercel 不稳定。需要一个“点开就能看”的保底展示：单个 HTML 文件，内嵌预先生成的真实结果，不联网、不调用任何接口，可放 GitHub Pages。

## 要做什么
1. `scripts/export-demo-data.mjs`：调用本机运行的 `/api/site` 与 `/api/report`，为四个案例（国贸、首钢园、亦庄、八达岭）生成并保存 `demo-data/cases.json`（含统计、简报、校验结果、模型名、生成时间）。设施坐标不保存。
2. `demo/template.html` + `scripts/build-demo.mjs`：把 `cases.json` 嵌入模板，输出 `docs/index.html`（GitHub Pages 从 `/docs` 发布）。
3. 页面内容：
   - 四个案例切换，展示统计表（封顶显示 ≥）与简报（含校验标记）。
   - 明确标注“预先生成的真实结果，非实时查询”及生成日期。
   - “它是怎么工作的”：流程图 + 说明“统计由代码、写作由模型、校验由代码”。
   - “校验拦截”：(a) 开发中真实发生的一次拦截案例（模型抄入提示词里的“3”）；(b) 可交互小工具：编辑简报文字，浏览器内实时运行同一套校验规则，标红不在统计表里的数字，并提供“注入一个编造的数字”按钮。
   - “数据局限”：POI 不等于用地性质、地铁按出入口、封顶、分类噪音、校验器已知局限。
   - 页脚：数据来源、技术栈、GitHub 与在线体验版链接占位。
4. 页面浅色/深色自适应，手机宽度可读，无外部依赖（无 CDN、无字体），单文件。

## 不许改
- `lib/`、`app/` 下的应用代码；`.gitignore`、`.env.example`、`docs/PRD.md`。
- 不许读取或打印 `.env.local`。

## 硬性约束
- 演示页内的校验函数须与 `lib/verify.ts` 行为一致，并用同一批测试用例做对照验证（附证据）。
- 页面中不得出现任何 Key、本机路径、学号或课程资料。
- 数据不得手工修改，必须来自导出脚本。

## 验收标准
1. `demo-data/cases.json` 四个案例均 `verified: true`。
2. 双击 `docs/index.html`（file:// 打开）可正常显示，断网也可用；浏览器控制台无报错。
3. 四个案例切换正常；统计表数字与 JSON 一致（脚本核对）。
4. 交互校验工具：未编辑时通过；注入编造数字后被标红且判定不通过；对照 `verify.test.ts` 用例，行为一致。
5. 手机宽度（375px）下无横向滚动；深色模式可读。
6. 全仓库搜索 Key 前 6 位无结果；文件大小合理（<1 MB）。
7. 交付说明：改动文件、验证方法、遇到的问题。

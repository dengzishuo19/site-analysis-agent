# 派工单 007：可视化——设施条形图与交互地图

状态：已完成并验收（有说明的偏差，见文末）

## 背景
目前只有统计表和文字简报。面试官第一眼需要“看懂”这个项目做了什么：一张可缩放、可点击的地图标出周边设施，加上各类设施的数量对比，比一张表直观得多。表格与简报保持不变，可视化作为补充。

用户选择**交互地图**：在线体验版直接使用；静态演示页优先使用交互地图（高德 JS 地图脚本在国内可访问，而静态演示页托管在 GitHub Pages，国内访问快），并保留**截图**作为兜底与 README 素材。

## 前置条件（需要用户在高德开放平台完成，执行方不得代办、不得索取任何 Web 服务 Key）
1. 新建一个 **Web 端（JS API）** 类型的 Key（与现有的“Web 服务”Key 是两个不同的 Key）。
2. 为它设置**域名白名单**：`127.0.0.1`、`dengzishuo19.github.io`、`site-analysis-agent-m6lm-livid.vercel.app`。（高德拒绝 `localhost`，已实测 `127.0.0.1` 可用；因此**本地测试必须用 `http://127.0.0.1:端口`**，不能用 `localhost`。）
3. 用户自己把该 Key 写入 `.env.local`：`NEXT_PUBLIC_AMAP_JS_KEY=...`，之后在 Vercel 环境变量里也添加一份。
4. 该 Key 天然会出现在浏览器里，安全性依赖域名白名单与高德的每日额度；这一点必须写入 README。

## 要做什么
1. **共享色板 `lib/palette.ts`**（纯常量与函数，无 import，应用、地图、条形图、静态演示页共用，构建演示页时由 Node 直接读取，只在此处维护）。已遵循 `dataviz` 技能并用其校验器计算得出：**该色板最多只有 4 种颜色能同时通过全配对检查**（蓝+黄+洋红+绿，浅色与深色均通过），而我们有 7 个类别，所以采用**复合编码**：
   - **颜色 = 类型族（4 种）**：交通（蓝）= 地铁站出入口 + 公交站；生活服务（洋红）= 教育 + 医疗 + 商业；公园绿地（绿）；工业（黄）。
   - **单字 = 具体类别**：地、公、教、医、商、园、工，显示在标记和图例里，作为第二编码；标记字色按底色亮度取深/浅，文字对比度须 ≥ 4.5:1。
   - 条形图的类别已在行首直接标注，条形按类型族着色，行首放与地图同款的单字徽标，用以和地图对应。
   - 浅色下洋红与黄对表面的对比度低于 3:1，按技能的“豁免规则”必须有可见文字标签与表格视图（统计表已存在）。
2. **两张条形图**（纯 HTML/CSS，不引入图表库，浅色/深色自适应）：
   - “各类设施数量”：每类一行，横向条形，行尾标数值；封顶类别显示“≥600”，条形末端渐隐或斜纹表示“实际更多”；数量为 0 显示“0”，不画条。
   - “最近设施距离”：每类一行，条形越短越近，行尾标“N m”；无设施的类别显示“—”。
   - 类别顺序固定，与统计表一致；有可访问的文字说明；375px 宽度下无横向滚动。
3. **交互地图组件**（高德 JS API 2.0，不引入 npm 依赖，动态加载脚本）：
   - 中心点标记、半径 1000 m 的圆；每类的全部已返回设施（每类最多 10 个）用按类别着色的标记，标记文字为类别单字（地、公、教、医、商、园、工）。
   - 点击/悬停标记显示信息窗：设施名、类别、距离。
   - 图例可点击：显示/隐藏某一类别的标记；图例同时说明颜色与单字的对应关系。
   - 初始视野让圆完整落在图内并留有边距；支持缩放与拖动。
   - 只使用地图渲染、标记、圆、信息窗，**不使用**需要“安全密钥”的服务插件（搜索、地理编码等）。若实测发现地图渲染本身也要求安全密钥，则必须通过服务器端代理转发并追加密钥，不得把安全密钥写进前端代码。
   - 加载失败（脚本被拦、Key 无效、白名单不匹配）时显示文字提示，不影响页面其他内容；不得出现空白大块或无限加载。
4. **应用页面**：统计表下方依次显示地图、两张条形图；纯函数 `lib/map-model.ts` 负责把统计数据转成“标记列表 + 圆参数 + 图例”，组件只负责渲染，便于单测。
5. **静态演示页**：
   - `scripts/build-demo.mjs` 从环境变量 `NEXT_PUBLIC_AMAP_JS_KEY` 读取 Key 并嵌入页面（构建时读取，不得写死在模板里）；页面用同一份色板与同样的标记规则显示交互地图与两张条形图。
   - 交互地图加载失败或断网（`file://` 打开时白名单可能不匹配）时，自动显示对应案例的**截图**并注明“交互地图不可用，显示截图”。
   - 四个案例各保存一张地图截图到 `docs/maps/{案例}.png`；演示页改为“`docs/` 目录自包含”（`index.html` + `maps/*.png`，相对路径引用）。
6. **截图**：执行方从运行中的应用与演示页各截取国贸、首钢园的地图与图表，放入 `docs/screenshots/`，README 引用。
7. 更新 `.env.example`（增加 `NEXT_PUBLIC_AMAP_JS_KEY` 空模板与说明）和 README（功能、Key 暴露与白名单说明、额度说明）。

## 输入 / 输出
- 输入：统计数据（设施经纬度已包含在 `/api/site` 的返回里，无需新增接口）。
- 输出：交互地图、两张条形图。

- 演示页里的图表数据模型与应用中的 `lib/map-model.ts`、图表模型行为一致，并用同一批用例做对照测试（沿用校验器的做法）。
- 前端不得出现“Web 服务”Key、DeepSeek Key、签名密钥、高德安全密钥。

## 验收标准（要有可运行证据）
1. `npm run build` 通过；`npm test` 通过。
2. 单测覆盖：标记数量等于各类设施总数；无设施的类别不产生标记；每个标记的经纬度、颜色、单字、信息窗文字正确；圆的中心与半径正确；图例与标记一致；同一输入输出相同；图表模型对封顶、零值、无设施类别的处理。
3. **浏览器实测（自动化）**：在本地生产模式下，输入国贸地址后：地图容器渲染出画布；标记数量等于统计数据；点击图例后对应类别标记消失/恢复；点击标记出现信息窗且内容与统计表一致；缩放后标记仍在；使用无效 Key 时显示失败提示而非空白。
4. **人工核对地图**：对国贸、首钢园，对照统计表确认中心标记位置、最近地铁口的方位、圆是否完整，交付说明附核对结论与截图。
5. **配色证据**：用 `dataviz` 技能的 `validate_palette.js` 对所用的 4 种颜色分别在浅色、深色模式下运行 `--pairs all`，结果附在交付说明；条形图按类别顺序的相邻配对也要通过。
   图表数字与统计表逐格一致（脚本核对）；浅色/深色下条形与背景对比度 ≥ 3:1，文字对比度 ≥ 4.5:1（给出计算结果）；375px 宽度无横向滚动。
6. 静态演示页：本地以 `http://` 打开时交互地图可用；断开脚本（模拟加载失败）时显示截图兜底；四个案例的截图齐全；推送后在 GitHub Pages 上验证交互地图可用（依赖用户已配置白名单）；与 `verify.ts` 无关的既有功能无回归。
7. 全仓库搜索“Web 服务”Key、DeepSeek Key、签名密钥的前 6 位无结果；抓取应用页面与演示页，确认不含这三者及安全密钥；`.env.local` 未入库。
8. 交付说明列出：改动文件、各文件作用、验证方法、遇到的问题，以及**这套可视化的局限**（含 JS Key 暴露的风险与白名单的边界、高德 JS 每日额度）。

## 待你决定
- **静态演示页是否也放交互地图？**推荐放：GitHub Pages 国内访问快，高德脚本国内可用，简历主链接就能直接展示交互地图。代价是 JS Key 会出现在公开仓库的 `docs/index.html` 里，只靠域名白名单防护——被人拿去在别处使用时会消耗你的高德 JS 每日额度，不会产生费用。不放则演示页只显示截图，更保守。（用户未反对，按“放”执行。）

## 执行记录：与原计划的偏差（如实）
1. **配色**：校验器计算表明色板最多 4 种色相能同时通过全配对检查，改为复合编码（颜色 = 4 个类型族，单字 = 7 个类别）；浅色下蓝用色阶第 500 档（`#256abf`），使标记上的白字对比度 ≥ 4.5。深色下最差色盲配对 6.9（6 到 8 的警告区间），由单字与图例作为第二编码。
2. **条形色对比度**：浅色下洋红（2.62）与黄（2.11）对表面低于 3:1，按技能的“豁免规则”由可见文字标签与统计表（表格视图）补偿，未能达到原验收写的“全部 ≥ 3:1”。
3. **兜底截图**由 `scripts/export-map-images.mjs` 用高德静态地图接口生成（读取本机 `AMAP_WEB_KEY`，不打印）；README 里的截图来自真实浏览器。
4. **域名失败无法探测**：实测发现 `data:`/`file:` 或不在白名单的域名下，高德脚本能加载但底图空白且不报错。因此改为“加载前判断”：只有 http(s) 协议且域名在白名单内才加载交互地图，否则直接显示截图。
5. **`localhost` 不被高德白名单接受**，改用 `127.0.0.1`，本地测试必须用该地址。
6. **地图缩放未能自动化验证**：滚轮与键盘缩放事件在测试环境中没有作用到高德地图；已验证初始取景（缩放级别 15 → 14.4，圆完整落在图内）、图例开关、信息窗内容与统计表一致。
7. 演示页的可视化模块由构建脚本用 Node 的 `stripTypeScriptTypes` 从 `lib/` 转译后嵌入，**应用与演示页共用同一份源码**，因此没有做“行为对照”测试。

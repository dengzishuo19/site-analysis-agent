# 派工单 011：可信度信息条、分享预览、关于、子类型更显眼

状态：已完成并验收（范围由用户确定，2026-10-04）

## 背景
作品集与简历已投出、不能再更新，HR 只能从在线版看到最新版本。在线版成了唯一的展示窗口，要让打开链接的人看懂它的价值。

## 要做什么（用户选定第 1、3、4、5 项；第 2 项“可核对的简报”不做）
1. **可信度信息条**：结果页顶部一条小信息条——统计数据已由服务器签名；简报校验结果（数字总数与逐一配对核对的个数，来自后端已有的 `coverage`）；已过滤的噪点数（链接到过滤规则与度量）。只展示后端已有的事实，不新增任何声称。
2. **分享预览**：页面标题、描述、Open Graph 标签与一张 1200×630 的预览图（`public/og.png`）。注意：微信对网页分享卡片的抓取不完全遵循 Open Graph，效果以实测为准。
3. **关于这个项目**：在线版页面底部与静态演示页顶部，**只放名字（邓子硕）与 GitHub 仓库链接**，不放电话、邮箱。
4. **子类型更显眼**：教育、医疗、工业的子类型分布直接显示在数量下方（只列数量非零的子类型），“调整口径”再展开复选框。

## 不许改
统计、过滤、校验、签名、简报的逻辑与接口。

## 验收
- 375 与 1280 宽度下信息条、关于、子类型标签无溢出、可读。
- 信息条里的数字与简报的校验结果、统计表的过滤数一致。
- 页面源代码里有正确的 og 标签，预览图可访问。
- 全部测试与类型检查通过。

## 交付说明
- 信息条文案：“✓ 统计由代码计算，并经服务器签名防篡改”“✓ 简报 N 个数字已全部核对，其中 M 个与具体设施或类别逐一配对”“已过滤 K 个噪点 · 查看规则与度量”。简报生成中、口径改变待重新生成、校验未通过各有对应文案。“全部核对”的含义：校验通过即所有数字都出现在统计表中，M 个另外做了名称—距离或类别—数量的配对核对。
- 实测：北京建筑大学（展览路 1 号）简报 44 个数字全部核对、43 个逐一配对、过滤 29 个噪点；教育子类型标签合计 21，与数量一致。375 与 1280 宽度下无横向滚动（地图内的标记被地图框裁切，不影响页面）。
- 分享标签已在页面源代码中确认（og:title / og:description / og:image 1200×630 / twitter:card），预览图 `/og.png` 可访问。**微信的分享卡片未实测**：微信对网页卡片的抓取不完全遵循 Open Graph，可能仍只显示标题。
- 静态演示页顶部加了“作者：邓子硕”与分享标签（预览图引用在线版的 `/og.png`，推送部署后才可访问）。
- 窄屏表头“数量”不再换行。
